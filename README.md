# Road-Rash-64-Carnage
Romhack for Road Rash 64
ROAD RASH 64 CARNAGE
Version 0.29

A fan-made enhancement for Road Rash 64, featuring nine new cheat codes:

Big Head Mode, 8x Damage, Giant Peds, Crazy Peds, Super Punch (100x damage), Tiny Bikes,
Unlock Everything (combines all original bike, track and mode unlock codes), Crazy Traffic, and Moon Gravity.

This version also refreshes distant riders' animations more frequently
to address the intermittent raised-arm pose seen on real hardware.
Initial testing on an N64 with Expansion Pak showed the issue resolved
with no noticeable extra slowdown. Further testing is welcome.

INSTALLATION
1. Start with an unmodified USA Road Rash 64 ROM in .z64 format.
   Required source SHA-1:
   87727a298f583ec8325f5655088ff21e37b335b2
2. Apply Carnage v0.29.bps using a BPS compatible patcher.
3. Load the resulting ROM in your emulator or compatible N64 flash cart.
   Fresh-boot the game; do not load a save state from an older version.

This is the complete patch. No earlier patches are needed.
The original game ROM is not included.

CHEAT CODES
Enter at the main menu, pressing each button separately & somewhat slowly.
A confirmation sound indicates acceptance.

Big Heads (4x):
C-Up, C-Right, C-Down, C-Left, C-Up, C-Right, L, Z

8x Damage:
R, Z, L, Z, R, L, R, Z

Giant Peds (8x):
L, Z, R, Z, L, R, L, Z

Crazy Peds (chasing with solid collisions):
C-Down, L, C-Down, R, C-Down, Z, L, R

Super Punch (powerful punches, kicks and weapons for all racers):
C-Right, L, C-Left, R, C-Right, Z, C-Left, Z

Tiny Bikes (one-third-size bikes, full-size riders):
C-Left, R, C-Right, L, C-Left, Z, C-Right, Z

Unlock Everything:
Z, C-Up, R, C-Down, L, C-Right, C-Left, Z

Crazy Traffic (traffic swerves toward racers):
C-Up, L, C-Down, R, C-Left, Z, C-Right, Z

Moon Gravity (airborne bikes and riders, normal grounded handling):
C-Up, C-Down, C-Up, C-Down, L, R, Z, Z

Codes can be combined. Repeating a code does not turn it off.
Reboot the ROM without loading a save state to reset the codes.
